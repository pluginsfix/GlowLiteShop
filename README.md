# GlowLiteShop

Кастомный магазин предметов в стиле HolyWorld Lite с аукционами, ставками, прямой покупкой, мультивалютностью и хранилищем покупок.

## Возможности

- **Два формата покупки**:
  - Прямая покупка по фиксированной цене;
  - Аукцион со ставками, минимальным шагом и возвратом перебитых ставок.
- **Поддержка валют**:
  - Настраиваемые монеты (Vault) и сапфиры (PlayerPoints / локальная база данных);
  - Гибкая кастомизация названий и символов валют.
- **Хранилище покупок (`/shop chest`)**:
  - Все приобретённые или выигранные предметы попадают в изолированное хранилище, предотвращая потерю вещей при переполненном инвентаре.
- **Автоматическая ротация ассортимента**:
  - Настраиваемый интервал обновления витрины;
  - Режим «Ранний вайп» (`early-wipe`), динамически ускоряющий смену товаров.
- **Интерактивная навигация**:
  - Быстрый переход в магазин китов и бустеров прямо из меню `/shop`.

## Команды

| Команда | Описание | Право |
|---|---|---|
| `/shop` | Открыть главное меню магазина | `glowliteshop.use` |
| `/shop chest` | Открыть хранилище купленных предметов | `glowliteshop.use` |
| `/shop bid <слот> <сумма>` | Сделать ставку на лот | `glowliteshop.use` |
| `/shop earlywipe [on\|off]` | Переключить режим раннего вайпа | `glowliteshop.admin.earlywipe` |
| `/shop forcerotate` | Принудительно обновить товары | `glowliteshop.admin.rotate` |
| `/shop reload` | Перезагрузить конфигурацию плагина | `glowliteshop.admin.reload` |

## Настройка

Все параметры цен, режимов продажи, предметов, таймеров и сообщений настраиваются в файлах `config.yml` и `messages.yml`.
